# middleeast.events

An interactive map and timeline of the Middle East, 1900 to the present:
events from Wikipedia and historically dated borders, with the source and
status of every border shown honestly.

Structure: `app/` (React + MapLibre frontend, a fully static site with
in-browser full-text search), `scripts/` and `data/` (ingestion and the cited
border-corrections pipeline). See DEPLOYMENT.md.

## Quick start

Needs Node.js 22 (`.nvmrc`; anything matching `^20.19.0 || >=22.12.0` in
`engines` should work, but CI and the tests use 22+).

```sh
npm ci                 # repo root: the data-pipeline scripts' dependencies
npm ci --prefix app    # app/: the frontend and its build tools
```

Two `package.json`/lockfile pairs on purpose: the site is built by Cloudflare
Workers Builds with `app/` as its root directory, so `app/` is a self-contained
package (React, MapLibre, Vite, Pagefind, wrangler). The repo root holds only
what the data scripts in `scripts/` need (geometry libraries for the border
pipeline), which the site build never installs.

| Task | Command |
|---|---|
| Run the site locally | `cd app && npm run dev` (first regenerates `app/public/data/`, the search index and `app/src/lib/dataVersion.js` from `data/`) |
| Unit tests | `npm test` (scripts/lib) and `npm test --prefix app` (app/src/lib) |
| Lint | `npm run lint --prefix app` |
| Production build | `cd app && npm run build && node scripts/check-dist.mjs` |
| Validate the event data | `node scripts/validate-events.js` |
| Border check | `node scripts/verify-borders.js --check` (CI); `npm run verify-borders` also rewrites `docs/border-verification.md` |

Everything under `app/public/data/`, `app/public/pagefind/` and
`app/src/lib/dataVersion.js` is generated by the build and gitignored; edit
`data/` instead. The data pipeline (discovering, enriching and merging events)
and the monthly Wikipedia refresh are described in
[docs/DATA_POLICY.md](docs/DATA_POLICY.md#pipeline-and-workflow) and
[DEPLOYMENT.md](DEPLOYMENT.md#ci-and-the-data-pipeline); deployment is automatic
on merge to `main` (DEPLOYMENT.md).
